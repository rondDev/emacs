* Emacs config
This repo serves as my own personal emacs configuration.
Feel free to use it, but there is no guarantee of stability.

Requirements:
- Cmake to compile [[https://github.com/akermu/emacs-libvterm][VTerm]]
- Requirements for [[https://github.com/manateelazycat/lsp-bridge#installation][lsp-bridge]]

To use:
#+begin_src bash
  git clone git@github.com:rondDev/emacs.git ~/.config/emacs
#+end_src
