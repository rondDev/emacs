# Emacs config

This repo serves as my own personal emacs configuration.
Feel free to use it, but there is no guarantee of stability.

Requirements:

-   Cmake to compile [VTerm](https://github.com/akermu/emacs-libvterm)
-   Requirements for [lsp-bridge](https://github.com/manateelazycat/lsp-bridge#installation)

To use:

    git clone git@github.com:rondDev/emacs.git ~/.config/emacs

## Guidelines:

-   Try to utilize elpaca (use-package) to do most of the things.
-   Custom variables and functions will be prefixed with `r/` while internal
    functions and variables will be prefixed with `r//`.
